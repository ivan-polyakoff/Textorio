# Textorio VK Bot

Textorio — это бот для ВКонтакте, который помогает в написании текстов для ютуберов и малого бизнеса с использованием нейросети Гигачат.

## Возможности

### Для ютуберов:
- Помощь в написании постов (`/пост <тема>`)
- Улучшение стиля текста (`/стиль <текст>`)
- Генерация текста по фото *(в разработке)*
- Обучение стилю автора *(в разработке)*

### Для малого бизнеса:
- Описание товаров и услуг (`/товар <описание>`)
- Ответы на вопросы и замечания клиентов *(в разработке)*
- Генерация рекламных текстов

### Общие функции:
- Интеграция с нейросетью Гигачат
- Монетизация через донаты ВКонтакте *(в разработке)*
- Возможность обучения под стиль автора

## Установка и настройка

1. Склонируйте репозиторий
2. Установите зависимости: `npm install`
3. Создайте файл `.env` на основе `.env.example` и укажите свои значения:
   ```
   VK_GROUP_TOKEN=ваш_токен_группы
   GROUP_ID=ваш_id_группы
   GIGACHAT_API_KEY=ваш_api_ключ_гигачат
   GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
   GIGACHAT_API_URL=https://gigachat.devices.sberbank.ru/api/v1/chat/completions
   GIGACHAT_FILES_URL=https://gigachat.devices.sberbank.ru/api/v1/files
   ```
4. Запустите бота: `npm start`

## Команды бота

- `/start` — открывает главное кнопочное меню
- `/стиль <текст>` — улучшает стиль указанного текста
- `/пост <тема>` — создаёт цепляющий пост по заданной теме
- `/фотопост` — запускает сценарий создания поста по фото
- `/товар <описание>` — генерирует продающее описание товара
- `/реклама <описание>` — создаёт рекламный текст для малого бизнеса
- `/ответ <ситуация>` — готовит ответ клиенту
- `/мойстиль` — показывает накопленные предпочтения по стилю (👍/👎 и замечания)
- `/сброситьстиль` — очищает память стиля
- `/админ бан <id> [часы]` — временно блокирует пользователя (только для `ADMIN_IDS`)
- `/админ разбан <id>` — снимает блокировку (только для `ADMIN_IDS`)

Основной сценарий — через кнопки: выберите раздел и задачу, затем отправьте обычным сообщением тему, текст, описание или фото без команды.

**Примеры:**
- `/пост Как начать зарабатывать в интернете`
- `/стиль Привет, сегодня поговорим о важной теме.`
- `/фотопост`, затем отправьте фото
- `/товар Эко-сумка из органического хлопка, прочная, стильная, многоразовая`
- `/реклама Кофейня у метро, скидка 20% на завтраки до 12:00`
- `/ответ Клиент недоволен задержкой доставки, нужно извиниться и предложить решение`

## Устранение распространённых ошибок

### Ошибка: "Long poll for this group is not enabled"

Если при запуске бота вы получаете ошибку `APIError: Code №100 - One of the parameters specified was missing or invalid: longpoll for this group is not enabled`, выполните следующие шаги:

1. Перейдите в настройки вашего приложения ВКонтакте: [https://vk.com/editapp?id=238319313](https://vk.com/editapp?id=238319313)
2. Выберите вкладку "Работа с API"
3. Найдите раздел "Long Poll API"
4. Нажмите "Настроить" напротив группы, в которой должен работать бот
5. Включите переключатель "Включить Long Poll API"
6. Нажмите "Сохранить"

Убедитесь, что `GROUP_ID` в вашем файле `.env` совпадает с ID группы, для которой вы включили Long Poll API.

### Ошибка: "Code №912 - This is a chat bot feature"

В сообществе ВКонтакте не включены возможности ботов для сообщений с клавиатурой. Откройте настройки сообщества и включите сообщения/бота:

1. Управление сообществом
2. Сообщения
3. Настройки для бота
4. Возможности ботов — включить

Пока настройка выключена, бот отправит текст без кнопок.

### Ошибка: "SELF_SIGNED_CERT_IN_CHAIN"

Node.js не доверяет одному из сертификатов в цепочке GigaChat. Надёжный вариант — скачать корневой сертификат НУЦ Минцифры/доверенный bundle в формате PEM/CRT и указать путь к нему:

```
GIGACHAT_CA_BUNDLE_FILE=certs/russian-trusted-root.pem
```

Для быстрой локальной проверки можно временно отключить проверку TLS:

```
GIGACHAT_REJECT_UNAUTHORIZED=false
```

Не оставляйте отключенную проверку сертификатов в продакшене.
